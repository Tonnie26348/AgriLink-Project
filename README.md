# Food Supply Chain - Digital Food Marketplace & Supply Chain Platform

Connecting farmers, food suppliers, retailers, wholesalers, and buyers through transparent trading, intelligent agricultural insights, and reliable digital commerce.

## Key Features

- **Direct Farmer-to-Buyer Marketplace:** Eliminate unnecessary intermediaries, secure fair pricing, and browse fresh produce listings.
- **M-Pesa Mobile Payments:** Integrated Safaricom M-Pesa STK push and secure callback webhooks for instant financial transactions.
- **AI Agricultural Suite:** AI Crop Diagnosis, AI Price Recommendations, Sales Forecasting, and AI Supply Chain Assistant.
- **Order Management & Tracking:** Real-time order fulfillment tracking and inventory management.
- **Role-Based Portals:** Dedicated dashboards for Farmers, Buyers, and Administrators.

## Technologies

- Vite 8 / React 18 / TypeScript
- Tailwind CSS / shadcn-ui / Radix UI
- Supabase (PostgreSQL, RLS, Storage, Realtime, Deno Edge Functions)
- Vitest

## Getting Started

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run tests
npm run test
```
